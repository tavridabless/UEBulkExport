# Как получить файл маппингов `.usmap`

[English](mappings.md) · **Русский**

## Зачем он нужен

Unreal Engine умеет сериализовать свойства объектов двумя способами. Редакторские и
отладочные сборки пишут свойства **с версиями**: перед каждым значением стоят имя и тип
свойства. Релизные сборки (shipping) пишут свойства **без версий**: имён уже нет, остаётся
голый поток значений, смысл которого зависит от точной раскладки каждого класса на момент
компиляции.

Так устроена любая релизная сборка UE5. Это не обфускация, и обойти это нельзя: нужной
информации в пакете действительно нет. Без описания раскладки классов `.uasset` — просто
неразборчивый набор байтов.

Файл `.usmap` и есть такое описание: выгрузка всех классов, структур и перечислений сборки
со свойствами в порядке объявления. С ним поток байтов можно пройти и вернуть каждому
значению его настоящее имя.

Понять, что он нужен, можно по сообщению:

```
This build stores properties unversioned and cannot be read without a mappings file.
```

Или, в других инструментах:

```
Package has unversioned properties but mapping file is missing, can't serialize
```

## Маппинги привязаны к сборке

Раскладка классов меняется вместе с кодом игры. `.usmap` подходит к той сборке, из которой
его сняли, и обычно к патчам, которые не трогают классы. После обновления игры снимите файл
заново. Устаревший файл не выдаёт явной ошибки, а молча даёт неверные значения, поэтому
лучше перегенерировать, чем гадать.

## Как получить его с помощью UE4SS

Пока игра запущена, раскладка классов лежит в памяти, в системе рефлексии Unreal.
[UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) (MIT) считывает её и записывает `.usmap`.

UE4SS — отдельный проект. UEBulkExport не включает его в себя, не связывается с ним и не
требует его: подойдёт `.usmap` из любого источника.

> Делайте это только с программами, которые вы вправе запускать и изменять. Внедрять
> библиотеку в игру с античитом или в программу, условия которой запрещают модификацию, —
> решение и ответственность пользователя.

### Шаги

1. Скачайте `UE4SS_*.zip` со [страницы релизов](https://github.com/UE4SS-RE/RE-UE4SS/releases)
   UE4SS. Сборка `experimental-latest` поддерживает более новые версии движка, чем последний
   помеченный релиз.

2. Распакуйте `dwmapi.dll` и папку `ue4ss` рядом с исполняемым файлом игры — тем, что лежит в
   `<Игра>/Binaries/Win64/`, а не рядом с лаунчером в корне игры.

3. Запустите игру и дождитесь главного меню.

4. Нажмите <kbd>Ctrl</kbd> + <kbd>Numpad 6</kbd>. Это стандартное сочетание UE4SS для
   `DumpUSMAP()`.

5. В папке `ue4ss` появится файл с названием игры и версией движка. Закройте игру.

6. Укажите этот файл в поле **«Маппинги»** на странице «Экспорт» или передайте его через
   `--usmap`:

   ```
   UEBulkExport.Cli --paks "D:\Games\MyGame" --out "D:\Export" --mode full --usmap "...\ue4ss\MyGame-5.3.2.usmap"
   ```

   Если положить единственный `.usmap` рядом с контейнерами игры (в папку `Paks` или на уровень
   выше) или в папку вывода, UEBulkExport найдёт его сам.

### Нет цифрового блока клавиатуры?

На ноутбуках обычно нет цифрового блока, и стандартное сочетание недоступно. В этом
репозитории есть небольшой мод для UE4SS, который вызывает `DumpUSMAP()` по таймеру: выгрузка
происходит сама через несколько секунд после запуска игры, а <kbd>Ctrl</kbd> + <kbd>F6</kbd>
позволяет повторить её вручную.

Скопируйте [`tools/ue4ss-mod/AutoUsmapDumper`](../tools/ue4ss-mod/AutoUsmapDumper) в
`ue4ss/Mods/` и добавьте в `ue4ss/Mods/mods.txt` строку, выше записи `Keybinds` в конце файла:

```
AutoUsmapDumper : 1
```

Если UEBulkExport установлен с компонентом «Инструменты UE4SS для получения mappings», этот мод уже лежит в папке
установки, в `tools\ue4ss-mod\AutoUsmapDumper`.

Запустите игру, подождите секунд двадцать и закройте её. Файл `.usmap` окажется в папке
`ue4ss`.

Чтобы видеть процесс, укажите `ConsoleEnabled = 1` в разделе `[Debug]` файла
`ue4ss/UE4SS-settings.ini`: UE4SS откроет окно консоли и запишет в него ход выгрузки.

### Как убрать UE4SS

UE4SS только добавляет файлы. Чтобы удалить его, удалите `dwmapi.dll` и папку `ue4ss` из
`Binaries/Win64`. Если после следующего патча понадобится снять маппинги заново, их удобно
оставить.

## Другие источники

- Некоторые игры сами кладут `.usmap` в свои контейнеры. Запустите `--mode list` и поищите его.
- Разработчики могут настроить движок так, чтобы он создавал файл при cooking. Если вы
  выгружаете собственный проект, это самый простой путь.
- Подойдёт и любой другой дампер рефлексии, который пишет формат `.usmap`.

## Версии формата

UEBulkExport читает те версии, которые поддерживает CUE4Parse; сейчас это в том числе версия 5
(`EngineVersioning`). Текущие сборки UE4SS создают файлы версии 4 (`ExplicitEnumValues`).
Старые инструменты, привязанные к ранним версиям CUE4Parse, могут отклонять такие файлы с
ошибкой `Usmap has invalid version` — это ограничение этих инструментов, а не файла.
